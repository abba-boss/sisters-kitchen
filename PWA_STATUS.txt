STEP 1: GENERATE ICONS (2 minutes)
────────────────────────────────────
Method A - Browser Generator (Easiest):
$ open frontend/scripts/generate-pwa-icons.html
  → Auto-generates icons
  → Click "Download All as ZIP"
  → Extract to frontend/public/icons/

Method B - Node.js Script:
$ cd frontend
$ npm install canvas        # One-time only
$ npm run generate:icons    # Generates all icons

STEP 2: START THE APP (30 seconds)
───────────────────────────────────
$ cd frontend
$ npm run dev

Open: http://localhost:5173

STEP 3: TEST PWA (2 minutes)
────────────────────────────
1. Open DevTools → Application
2. Check Service Workers → "activated and running"
3. Check Manifest → Verify 8 icons load
4. Wait 3 seconds → Install prompt appears
5. Test offline: Network → Offline → Reload
